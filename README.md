**Costa Serena** — an original 3D open-world crime game that plays offline in a desktop browser. Explore a sun-soaked tropical coastal city on foot or by stealing and driving any car: traffic AI, pedestrians, a 0–5 star wanted system with pursuing police, pistol combat, a four-mission story chain from fixer Marina Sol plus repeatable side gigs, a full HUD with a live minimap, and procedural WebAudio sound and music. Built with three.js (vendored) and plain ES modules; no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play with keyboard and mouse. To hand the game in the way the grader does: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
